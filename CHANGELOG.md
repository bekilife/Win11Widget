# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-18

Первый публичный релиз.

### Виджеты
- Часы, календарь, «Сейчас играет», погода с несколькими городами, система.
- «Система» компактная, по наведению раскрывается полная версия: CPU, RAM, NVIDIA GPU с температурой и VRAM, сеть, время работы, все диски.
- Монохромное оформление в едином стиле, эффект стекла из обоев рабочего стола.

### Поведение
- Виджеты живут на уровне рабочего стола и не скрываются по Win+D.
- Сетка с отступами 16 px, примагничивание при перетаскивании, нижние виджеты следуют за изменением высоты.
- Иконка в трее, автозапуск, окно редактирования городов.

### Технические
- Тяжёлые операции (метрики, обои, медиа) выполняются вне UI-потока; обои кэшируются.
- Включена политика безопасности контента (CSP).
- Идентификатор приложения сменён на `com.win11widget.desktop`; настройки предыдущих версий переносятся автоматически.
- Иконка приложения в классическом формате ICO (BMP-кадры), корректно отображается в Проводнике.
