# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [1.0.0] — 2026-11-24

Первый публичный релиз.

### Виджеты
- «Курсы»: доллар к тенге (цена продажи в обменнике mig.kz), биткойн и Gram к доллару с Binance с изменением за сутки.
- «Сейчас играет»: обложка, трек, прогресс и кнопки управления для любого плеера; обложка догружается, если плеер публикует её с задержкой.
- «Погода»: основной город с прогнозом на 6 часов и другие города с местным временем (Open-Meteo, без ключа); неудачный запрос повторяется через 20 секунд.
- «Система»: компактная, по наведению раскрывается полная версия — CPU, RAM, видеокарта любого производителя с температурой, VRAM, мощностью и вентилятором (D3DKMT), сеть, время работы, все диски.

### Оформление и поведение
- Эффект стекла из обоев рабочего стола одинаковой тёмной яркости на любых обоях; при смене обоев обновляется сам.
- Виджеты живут на уровне рабочего стола, не скрываются по Win+D, не видны в панели задач и Alt+Tab.
- Сетка с отступами 16 px, примагничивание при перетаскивании, нижние виджеты следуют за изменением высоты.
- Иконка в трее, автозапуск, окно редактирования городов. После перезапуска Проводника всё восстанавливается.

### Технические
- Чистый Win32 на Rust: слоистые окна, Direct2D и DirectWrite, WinHTTP, WIC; без WebView2.
- Один процесс, около 13 МБ памяти, один exe около 600 КБ без установщика.
